# Wanderwise-Java-Chatbot-

<h2>Problem Statement </h2>
Planning a trip can be stressful and time-consuming, as it often involves separately researching destinations, hotels, and local attractions. The challenge is to create an easy-to-use, all-in-one solution that provides detailed travel information and makes trip planning simpler and more enjoyable. <br>
<h2>Our Solution </h2>
Wanderwise is a Java-based chatbot designed to assist travelers with their travel and tourism needs through an interactive conversation. The chatbot provides:
•	Information on destinations: Descriptions of cities, tourist attractions, and hidden gems. <br>
•	Hotel recommendations: Details of nearby accommodations and options based on budget. <br>
•	Local tips and advice: Suggestions for activities and cultural insights. <br>

<h2>Tech Stack Used</h2>
•	Programming Language: Java <br>
•	GUI Framework: Java Swing (for the graphical interface) <br>
•	Data Structures: HashMaps (for storing questions and answers) <br>
•	User Input Handling: StringTokenizer (for tokenizing and comparing user queries) <br>
•	Planned Extension: Database integration for efficient data management <br>
