# Wanderwise-Java-Chatbot-

WANDERWISE
Problem Statement
Planning a trip can be stressful and time-consuming, as it often involves separately researching destinations, hotels, and local attractions. The challenge is to create an easy-to-use, all-in-one solution that provides detailed travel information and makes trip planning simpler and more enjoyable.
Our Solution
Wanderwise is a Java-based chatbot designed to assist travelers with their travel and tourism needs through an interactive conversation. The chatbot provides:
•	Information on destinations: Descriptions of cities, tourist attractions, and hidden gems.
•	Hotel recommendations: Details of nearby accommodations and options based on budget.
•	Local tips and advice: Suggestions for activities and cultural insights.

Tech Stack Used
•	Programming Language: Java
•	GUI Framework: Java Swing (for the graphical interface)
•	Data Structures: HashMaps (for storing questions and answers)
•	User Input Handling: StringTokenizer (for tokenizing and comparing user queries)
•	Planned Extension: Database integration for efficient data management
